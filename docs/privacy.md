# 隐私与安全

## 默认数据流

工作台读取当前 Vault 配置目录中的 Markdown，并在用户确认后向同一 Vault 写入记录或报告。CSV/JSON、进展/纪要文本和本地原型收件在本地处理。v0.1.0 没有业务网络请求、遥测、第三方 AI 服务、API Key 配置或 TAPD 账号登录。

插件安装、npm 依赖安装、BRAT 更新、Obsidian Sync、其他同步工具、其他插件以及你主动打开的外部链接和原型，不在“本插件不联网”的保证范围内。它们各自有独立的数据流和隐私设置。

## 安全使用

- 首次接入真实记录前备份 Vault，并先在测试 Vault 演练导入
- 只安装可信来源的同版本发行文件；社区插件通常能访问 Vault，不应把安装视为零风险操作
- 进展正文可能含商业敏感信息，请按团队规则控制 Vault、同步和分享范围
- 不导入密码、API Key、访问令牌或不必要的个人隐私；来源 URL 不应包含登录凭据
- 容量仅记录计划所需的小时数，不必记录请假的健康原因或其他敏感原因
- 不把负荷视图用于个人绩效排名或自动人事决策
- 对非法日期、重复 ID、容量未知、过期记录和导入警告逐条复核
- 报告保存后仍是普通文件；任何邮件发送、外部共享或复制都由使用者决定

## 修改与冲突

任务修改会核对来源路径、记录身份和更新时间，帮助避免覆盖已变化记录。它不是多用户事务系统；外部编辑、同步冲突和手工改 YAML 仍需检查。原型导入也不是跨文件事务，保存中断可能保留已复制的资源；应按错误提示核对文件和版本记录，不能假定整批回滚或再次覆盖。基线是工作流冻结，不阻止管理员、其他插件或文本编辑器修改它。

## 报告问题

公开 Issue 或聊天中的示例请脱敏。建议附插件版本、Obsidian 版本、复现步骤、虚构最小样例、预期与实际结果。不要附原始 Vault、员工详情、客户信息、密钥或未脱敏系统链接。

如需处理安全缺陷，优先使用维护者实际提供的私密联系渠道；本仓库不编造不存在的安全邮箱或承诺响应时限。

## 会议与资料来源

会议保存人工提供的原文和录音/转写来源链接，不录音、不下载音频、不调用转写或 AI 服务。保存纪要会增加 Vault 中可被同步、备份及搜索的内容；只录入必要信息，并遵守参与者知情及团队保密要求。对转写中的错误、讨论与实际决定应人工核对。

资料版本保留提供者、来源、URL/原始文件与历史版本；任务和会议固定到确切版本。来源可信度不会因为保存、采用或人工预览而自动提高。在线来源仍可能被来源方修改；保存一个 URL 不等于锁定远端网页内容。不要在来源 URL 中保存用户名、密码、令牌或带凭据的临时链接。

## 原型是可执行的外来内容

文件夹、HTML 和 ZIP 中的页面可能包含 JavaScript、第三方资源及外部请求。插件只检查收件结构与资源边界，不在插件页面里执行原型、不嵌入 iframe、不启动服务器、不把资源上传到站点。原型的网络/登录要求及预览结果保留为人工记录，未知不会自动改成安全或通过。

ZIP 导入拒绝越界路径、链接与特殊条目、重复/冲突路径及超出限制的包，并校验归档结构与 CRC。这不等同于恶意代码扫描、漏洞检测或安全认证。只打开可信来源的内容，必要时先由安全工具或隔离浏览器检查。

主动在系统默认外部应用打开本地入口后，页面自身仍可以运行脚本或联网，浏览器可能发送请求、Cookie 或其他已有站点上下文。打开线上 URL 会直接联系该站点。本插件不替用户接受权限提示、登录、保存凭据或提交表单。支持本地外部打开的是桌面 Electron 适配器；移动端本地打开明确不支持，线上 URL 仍可用。

全部演示原型只登记虚构 URL 或本地引用，不创建、托管或运行资源；演示 URL 均为 example.com，不包含真实来源、账户或会议录音。
